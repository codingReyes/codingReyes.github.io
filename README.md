# Guillem González — Research Portfolio

Cyberpunk-inspired academic/research portfolio, built with plain HTML and CSS and deployed with GitHub Pages.

## Files
- `index.html`: all page content and sections
- `style.css`: theme, layout, responsive rules

## Preview locally
Open `index.html` in a browser. For a local server, from this folder:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Deploy using GitHub Pages
1. Create a repository named **`codingReyes.github.io`** under your GitHub account.
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under *Build and deployment*, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment. The site should appear at `https://codingReyes.github.io/`.

If using a different repository name, Pages normally publishes at `https://codingReyes.github.io/repository-name/`. You can still configure it in Settings → Pages.

## Important publication check
The publications included here are a starter selection based on publicly discoverable records. Cross-check your Google Scholar profile and update/add every publication. One 2026 presentation entry is deliberately marked “VERIFY” because official bibliographic details were not verified.

## Editing
- Change biography/project/paper text directly in `index.html`.
- Change palette and design variables at the top of `style.css` (`:root`).
- Before publishing, verify that your exact official lab address is correct and that you are comfortable publishing it.
